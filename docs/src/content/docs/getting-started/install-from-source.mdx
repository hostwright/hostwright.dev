Hostwright is in active development and not production ready.

<Aside type="caution" title="No package-manager install">
`brew install hostwright` does not exist today. A vendor tap, signed and
notarized archives, and a `.pkg` are planned. The current install path is a
source build.
</Aside>

## Requirements

- Apple silicon Mac.
- macOS 26 or newer for the current package target.
- Swift 6.2-compatible toolchain.
- Apple `container` only for live runtime commands.
- Git.

## Build and verify

```bash
git clone https://github.com/hostwright/hostwright.git
cd hostwright
swift build
swift test
scripts/integration.sh
swift run hostwright --version
swift run hostwright capabilities --json
```

This prints the current development version. There is no release tag to check
out yet; build from the default branch. The build produces four executables:
`hostwright` (the CLI), `hostwright-control` (one-shot local control),
`hostwrightd` (the foreground daemon), and `hostwright-dist` (distribution and
installed-lifecycle tooling). Locate them with `swift build --show-bin-path`.

## Try the current safe surface

```bash
swift run hostwright init
swift run hostwright validate
swift run hostwright plan --output json
swift run hostwright doctor --output json
```

Runtime-backed and state-writing commands need Apple `container` as applicable.
They use the state database at
`~/Library/Application Support/Hostwright/state/state.sqlite` by default, or an
explicit `--state-db` path:

```bash
swift run hostwright status
swift run hostwright logs api
swift run hostwright events
swift run hostwright cleanup --dry-run
swift run hostwright paths --json
```

`hostwright-dist` implements an installed lifecycle (install, upgrade, repair,
rollback, uninstall) for a verified artifact at an explicit prefix, plus a
trusted release pipeline. A published package channel needs credentialed
release evidence that is not yet in place, so the current install path stays a
source build. The source checkout is separate from an installed prefix;
deleting the checkout does not uninstall or remove state.
