Hostwright `0.0.2-dev` is not GA or production-ready.

<Aside type="caution" title="Qualification build only">
`brew install hostwright` is not available. The Hostwright tap installs an
unsupported qualification build. Do not use it as a production release.
</Aside>

## Vendor tap

```bash
brew install hostwright/tap/hostwright
hostwright --version
hostwright capabilities --json
```

The current tap formula installs the immutable `v0.0.2-dev.12` qualification
release. See the [core install guide](https://github.com/hostwright/hostwright/blob/main/docs/reference/install.md)
for its precise package lifecycle and data-preservation rules.

## Build from source

Requirements:

- Apple silicon and macOS 26 or later;
- Xcode command-line tools with a Swift 6.2-compatible toolchain;
- Apple `container` for runtime-backed commands.

```bash
git clone https://github.com/hostwright/hostwright.git
cd hostwright
swift build
swift test
swift run hostwright --version
swift run hostwright capabilities --json
```

Source builds use the pinned package dependencies. Build output is not a signed
release artifact. Use [Compatibility](/reference/compatibility/) and
[Limitations](/reference/limitations/) to check the supported development
boundary.

## Upgrade, recovery, and rollback

Signed package upgrade, repair, recovery, rollback, and uninstall are
implemented for the development distribution lifecycle. GA qualification for
the final `v0.0.2` bytes is still pending. Preserve the install prefix and
state files during recovery; use the explicit lifecycle commands documented
in the [core installed lifecycle guide](https://github.com/hostwright/hostwright/blob/main/docs/reference/installed-lifecycle.md).
