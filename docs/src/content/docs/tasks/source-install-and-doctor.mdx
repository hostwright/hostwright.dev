title: Source install and doctor
description: Build the current development CLI and run its safe local host checks.
---

This workflow builds from source and runs local checks. It does not qualify a
signed `v0.0.2` release.

## Build from source

```bash
git clone https://github.com/hostwright/hostwright.git
cd hostwright
swift build
swift run hostwright --version
swift run hostwright capabilities --json
```

The package targets Apple silicon and macOS 26 or later and uses Swift tools
6.2. For the unsupported qualification build, the vendor tap command is
`brew install hostwright/tap/hostwright`; `brew install hostwright` is not an
available install path.

## Check the host

```bash
swift run hostwright doctor --output json
swift run hostwright runtime providers --json
```

Doctor performs safe local checks. It does not run a workload or prove that
every advertised provider capability is qualified for release. Runtime-backed
commands need Apple `container` and the exact provider prerequisites.
