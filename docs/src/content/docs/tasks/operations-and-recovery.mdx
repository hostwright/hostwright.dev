Use the current command help and
[CLI reference](/reference/cli/) for the exact build-specific options.
State-backed commands use Hostwright's secure Application Support database by
default. `--state-db <path>` or `HOSTWRIGHT_STATE_DB` selects a different
database.

## Inspect

```bash
hostwright status hostwright.yaml
hostwright logs web
hostwright events --output json
hostwright recovery --output json
hostwright doctor --output json
```

Status and logs may record observations. Events and recovery inspect retained
local evidence. Output is bounded and redacted; it is not an upload.

## Recover safely

If a command reports interrupted or ambiguous state, preserve the database and
owned resources. Read the recovery report and follow the command's specific
recovery path. Do not delete state files, retry with a stale plan, or clean up
resources based on names.

## Support bundles

Use `hostwright diagnostics support preview` to inspect the sections and size
before creating a bundle. Creation requires the current preview hash and an
explicit output path. Review the resulting local file before sharing it.
Hostwright does not upload support bundles automatically.

Read [Security and safety](/operations/security-and-safety/) and the
[core operations guide](https://github.com/hostwright/hostwright/blob/main/docs/reference/installed-lifecycle.md)
before install or recovery mutations.
