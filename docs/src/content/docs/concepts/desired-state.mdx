---
title: Desired state
description: Hostwright separates declared state from observed runtime state and computes the difference deterministically.
---

Hostwright separates versioned intent from observed provider facts. Manifest v3
requires explicit CPU and memory requests and limits for executable services.
The reconciler computes deterministic drift and a reviewable plan. An authenticated
local daemon executes confirmed lifecycle intent through durable, fenced operation
groups and can reconcile supported owned drift using recorded restart policy.

State uses the secure Application Support default unless an operator selects another
path. Intent and checkpoints are recorded before external effects; recovery
re-observes exact owned resources before replay. No SQLite transaction performs
runtime mutation, and unmanaged resources are never inferred from names.

Read the [manifest reference](/reference/manifest/), [reconciler](/concepts/reconciliation/),
[state store](/concepts/state-store/), and [lifecycle command reference](/reference/cli/).
Multi-Mac authority and scheduler optimization are deferred from this release.
