Hostwright `0.0.2-dev` is not production-ready. The v0.0.2 target is a single
Apple silicon Mac with the CLI, local scheduler, narrow Compose conversion,
and native desktop console. All claims below are bounded by the exact build
and evidence available for it.

## Implemented development surfaces

- Manifest v3 validation, explicit resource requests and limits, deterministic
  planning, and confirmed local lifecycle operations through authenticated
  Control API 2.2.
- Apple `container` and Containerization 0.35.0 provider adapters, each limited
  to the capabilities it declares.
- SQLite schema v24, durable ownership and reservation records, recovery, and
  local privacy-safe support bundles.
- A narrow Compose importer that converts supported fields for operator
  review; unsupported input is rejected.
- A native app for authenticated up, down, and restart with confirmation.

Implementation status does not mean release qualification is complete. Current
source must still pass physical-host lifecycle and soak work, desktop and
accessibility checks, VM install/upgrade/recovery, security review, and signed
artifact verification.

## Outside the v0.0.2 scope

| Area | Boundary |
| --- | --- |
| Multi-Mac | No cluster membership, quorum, remote placement, or cross-host recovery. |
| Kubernetes | No Kubernetes, CRI, CNI, CSI, kubelet, or Helm compatibility. |
| Docker ecosystem | No Docker API or client compatibility; no full Compose compatibility. |
| Scheduling | No topology optimization, automatic preemption, or cross-host placement. |
| Accelerators | No direct guest GPU/ANE passthrough or host-native accelerator service. |
| Desktop | No team, MDM, cloud, or automatic update service. |
| Support | No production support SLA, hosted diagnostics, telemetry upload, or cloud control plane. |
| Release | `v0.0.2` is not GA until protected release and artifact evidence gates pass. |

<Aside type="note">
`hostwright capabilities --json` reports the exact implemented surface for a
build. It does not establish compatibility outside the tested host, OS,
runtime, and artifact versions.
</Aside>

See the [core limitations reference](https://github.com/hostwright/hostwright/blob/main/docs/reference/limitations.md)
