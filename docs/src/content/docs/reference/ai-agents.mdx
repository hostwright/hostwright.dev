Hostwright `0.0.2-dev` is not GA-qualified. Its current contract is Manifest
v3, Control API 2.2, Runtime Provider API v2, and SQLite schema v24. Use the
core [CLI reference](https://github.com/hostwright/hostwright/blob/main/docs/reference/cli.md)
and [Manifest reference](https://github.com/hostwright/hostwright/blob/main/docs/reference/manifest.md)
for exact flags and fields.

<Aside type="caution" title="Review before runtime changes">
Validation and planning are non-mutating. Lifecycle and cleanup commands can
change local resources. Never confirm or execute them without the operator's
explicit approval of the current plan.
</Aside>

## Give the assistant these rules

```text
Hostwright is a development release for one Apple silicon Mac. It is not
GA-qualified. Do not claim Kubernetes, Docker API, full Compose, multi-Mac,
accelerator passthrough, or production support.

Use Manifest v3 and require explicit CPU and memory requests and limits. Do
not invent fields or silently drop unsupported input. Use `hostwright help`
and the current CLI and Manifest references for exact commands.

Safe inspection includes `hostwright --version`, `capabilities --json`,
`runtime providers --json`, `validate`, `plan`, and `doctor`. Ask before any
runtime mutation, install lifecycle change, or cleanup. For a lifecycle
operation, run the documented dry-run first and present its complete plan.
Proceed only after I approve that exact plan, then use its current hash with
the matching confirmed command. Never reuse a stale hash.

Cleanup has a separate dry-run and confirmation token. It may remove only
exact Hostwright-owned resources proven eligible by the current plan. Never
delete resources based on names or inferred ownership.

Do not put credentials in manifests, command arguments, logs, issue reports,
or support bundles. Support bundles require preview and confirmation; review
their contents before sharing. Do not upload diagnostics automatically.
```

For a source build, use the commands in
[Install and upgrade](/getting-started/install-from-source/). The vendor tap
offers an unsupported qualification build; `brew install hostwright` is not
available.
