Use the exact checked source and [installation guide](/getting-started/install-from-source/).
Hostwright is an unsupported development prerelease. Do not infer GA support from
implemented commands or earlier development evidence.

The current interfaces are Manifest v3, Control API 2.2, Runtime Provider API v2,
and SQLite schema v24. Every executable service requires explicit CPU and memory
requests and limits. Preview legacy v1/v2 migration before replacing any manifest.

Validate and plan first. Confirmed lifecycle mutation requires a fresh observed-runtime
dry-run hash and an authenticated local daemon. Inspect `hostwright paths --json`
for the selected secure state layout. Preserve unmanaged resources and existing files.
Never invent a confirmation token, skip ownership checks, or silently drop fields.

The accepted release is single-Mac. Multi-Mac, Kubernetes, Docker API/client parity,
accelerators, scheduler optimization, team/MDM/cloud features, automatic updates,
and Homebrew-core publication are deferred. Use [CLI](/reference/cli/),
[manifest](/reference/manifest/), and [compatibility](/reference/compatibility/) as authority.
